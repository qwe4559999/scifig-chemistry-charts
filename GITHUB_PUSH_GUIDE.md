# GitHub Push Guide

This repository is initialized on branch `main` with `origin` configured to:
`https://github.com/qwe4559999/scifig-chemistry-charts.git`

## Push Steps

1. Create an **empty** repository named `scifig-chemistry-charts` on GitHub (`https://github.com/new`).
   - Do **not** initialize with README, `.gitignore`, or license (they are already committed locally).
2. Push from this directory:

```bash
git push -u origin main
```

## Recommended Repository Metadata
- **Description**: `Origin-free declarative scientific figure engine, 9-type chemistry chart asset library, blind data-to-figure planner, and AI agent skill.`
- **Topics**: `scientific-visualization`, `matplotlib`, `chemistry`, `spectroscopy`, `reproducibility`, `ai-agent-skill`
